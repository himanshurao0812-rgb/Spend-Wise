# 📌 Project Overview
The Expense Tracker is a web-based application built using React that helps users manage their daily income and expenses efficiently. Users can add transactions, categorize them, and view their financial summary in a simple and interactive interface.

This project focuses on providing a clean UI and real-time updates using React fundamentals without complex logic.

# Features
- Add income and expense transactions  
- Categorize transactions (Food, Travel, Entertainment, etc.)  
- Real-time balance calculation  
- Expense summary (Income vs Expense)  
- Budget limit warning (optional feature)  
- Data persistence using Local Storage  
- Clean and responsive UI  

# Tech Stack
- Frontend: React.js  
- Styling: CSS / Tailwind CSS  
- State Management: React Hooks (useState, useEffect)  
- Storage: Local Storage  

# How It Works
- Users can add a transaction by entering a description and amount.  
- Positive values represent income, while negative values represent expenses.  
- The app automatically updates:
  - Total balance  
  - Total income  
  - Total expenses  
- All transactions are stored in the browser using Local Storage.

# Concepts Used
- React Components  
- Props and State  
- Event Handling  
- Conditional Rendering  
- Local Storage Integration
